## Base URL

```
https://data-tools.prd.space.id
```

## Authentication

Send your API key in the `X-API-Key` header on every request:

```bash
curl "https://data-tools.prd.space.id/api/v1/equity/quote?symbol=AAPL" \
  -H "X-API-Key: $ARRAYS_API_KEY"
```

[Full auth guide →](/api-reference/authentication)

## Response envelope

Every endpoint returns the same shape:

```json
{
  "success": true,
  "request_id": "req_abc123",
  "data": [ ... ]
}
```

`data` is **always an array**, even for single-record results.
