---
title: "Core Concepts"
description: "Key terms you'll see across Skills, the API, and Nanopayment."
---

<AccordionGroup>
  <Accordion title="Skill">
    A Markdown file (`SKILL.md`) that teaches an LLM agent how to use a slice of the Arrays API. Each Skill covers one domain (e.g. *equity fundamentals*, *crypto futures*) and lists the endpoints, parameters, and example prompts the agent should follow. Skills are open-source at [github.com/ArraysData/arrays-skills](https://github.com/ArraysData/arrays-skills).
  </Accordion>

  <Accordion title="Endpoint">
    A single REST URL that returns one type of data. Arrays exposes 114+ endpoints grouped by domain. Each Skill bundles related endpoints together with usage guidance — so the agent doesn't have to read raw OpenAPI specs.
  </Accordion>

  <Accordion title="API Key">
    A string identifying your account. Sent as `X-API-Key: <key>` header on every REST request. Free tier comes with a daily quota; Pro lifts it and unlocks higher-tier endpoints.
  </Accordion>

  <Accordion title="Nanopayment">
    One of two billing models (the other is a **subscription**). Pay-per-call access via the **x402** HTTP standard + Circle Gateway: your wallet signs an EIP-3009 USDC authorization, the server returns data, and settlement happens in ~500ms. **No signup, no API key.** Works with both Skills and the REST API. Today covers 15 crypto endpoints (\$0.008–\$0.03 / call); stocks and macro coming next.
  </Accordion>

  <Accordion title="Response envelope">
    Every Arrays endpoint returns the same JSON shape:

    ```json
    { "success": true, "request_id": "...", "data": [ ... ] }
    ```

    `data` is **always** an array, even for single-record results. Errors return `success: false` with an `error` object.
  </Accordion>

  <Accordion title="Fiscal vs. Calendar quarter">
    Many US companies have fiscal years that don't align with calendar years (Apple's FY ends in September, Microsoft's in June). When you ask for "AAPL Q2 earnings" Arrays defaults to the **fiscal** quarter. Specify `CY 2025` or a date range to force calendar interpretation.
  </Accordion>
</AccordionGroup>
